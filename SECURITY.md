# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability related to this project, please do not publish it publicly before reporting it.

Instead, open a private issue or contact the project maintainer with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

Reports will be reviewed and addressed as soon as possible.

---

## Scope

This repository is intended for educational and portfolio purposes.

Any integrations with third-party services should be tested only in environments that you own or are authorized to assess.

---

## Responsible Disclosure

Please practice responsible disclosure and avoid exploiting vulnerabilities beyond what is necessary to demonstrate the issue.
