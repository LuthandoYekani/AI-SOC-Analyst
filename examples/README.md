# Examples

This folder contains example inputs and outputs generated by the AI-Powered SOC Incident Analysis Assistant.

These examples demonstrate how the workflow transforms a structured security alert into a professional SOC incident analysis report.

## Files

- **sample-alert.md** – Example security alert provided to the workflow.
- **sample-analysis.md** – Example AI-generated incident analysis.

These files are intended for demonstration purposes and do not represent real-world security incidents.
